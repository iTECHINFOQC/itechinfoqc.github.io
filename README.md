## 🚀 Deployment
This site is designed to be hosted on **GitHub Pages**.
1.  Push `index.html`, `style.css`, and `script.js` to the `main` branch.
2.  Go to **Settings > Pages**.
3.  Select `main` branch as the source.
4.  The site will be live at `https://yourusername.github.io/itechinfo` (or your custom domain).
